# 🎓 Репетитор из Коми

Платформа подготовки к **ЕГЭ/ОГЭ по математике**: реальные варианты, автопроверка,
геймификация и кабинет преподавателя.

## Что умеет

- **Варианты ЕГЭ** — реальные задания с таймером, автопроверкой части 1 и разбором;
  часть 2 проверяет преподаватель (или ИИ-симуляция).
- **Банк заданий** — 19 тем кодификатора, тренажёр по теме, «Задача дня».
- **Геймификация** — XP, уровни и титулы (Новичок → Гроссмейстер ЕГЭ), серия дней
  со «страховкой» (streak freeze), 25+ достижений, марафон на скорость.
- **Аналитика** — график баллов и «ошибок 0.1», тепловая карта номеров,
  еженедельный отчёт, теги причин ошибок.
- **Рейтинг** — публичная лига (только ники, без имён), реферальная система
  «Приведи друга».
- **Кабинет преподавателя** — импорт задач (JSON), публикация авторских
  вариантов со ссылкой для учеников, список учеников.
- **Автономный режим** — без бэкенда работает на localStorage (демо);
  с бэкендом — полноценная база PostgreSQL.

## Быстрый старт (локально)

### Фронтенд

```bash
npm install
npm run dev        # http://localhost:5173
```

Для подключения к бэкенду создайте `.env` из `.env.example` и укажите
`VITE_API_URL`. Без него — автономный демо-режим.

### Бэкенд (опционально)

```bash
cd backend
python -m venv .venv && .venv\Scripts\activate     # Windows
pip install -r requirements.txt
cp .env.example .env                               # и заполните
uvicorn app.main:app --reload                      # http://localhost:8000/docs
```

Мастер-аккаунт преподавателя создаётся автоматически: **daniil / Pudov-Ege-2026** (код ученикам `SYSOLA-PRO` — отсылка к реке Сысоле, без фамилии).
